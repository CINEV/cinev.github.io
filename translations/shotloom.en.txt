Describe the desired action in a sentence, compare generated candidates, and apply one to the character's timeline.
1. Generate an action
Motion
 tab, open
Create New Motion
 and enter the action description and settings. Example: Slowly wave your right hand while standing in place.
2. Compare candidates
 — Select a generated candidate to preview it on the character. Use
Play Preview
 to review it again if needed.
3. Apply to the timeline
 — Run Add Performance Clip on the candidate. A Performance Clip is an action clip applied to a character's timeline. Confirm the target character and application range, then click
Add Clip
4. Play the applied result
 — Exit the candidate preview and play the actual timeline clip. Confirm that the selected character performs the desired action during the specified interval.
Candidate previews, clip application, and poses
The Shot must contain a character, and motion generation must be available.
Generating and previewing a candidate alone does not add it to the timeline. You must specify a target character and interval, then add the clip.
To apply a pose, open the
Pose
 tab, select a candidate, and specify the target character.
Place camera keys to change the composition over time and play the scene to review the movement. A camera key stores the camera composition at a particular frame.
1. Select a camera and composition
 — Select the camera to edit and compose the shot in pilot view. Pilot view lets you edit a scene while looking through the selected camera.
Check the composition from the selected camera's viewpoint
2. Save the starting composition
 — Go to the starting frame, adjust the composition, and save a camera key. After entering values, you must also execute the key-save action.
3. Save the next composition
 — Move to a later frame, enter the position and rotation for the next composition, and save them as a key.
Composition values, FOV, and multiple cameras
Enter the next composition's position and rotation at a later frame
Enter position and rotation values in Properties, then save a key. If you saved position and rotation keys together, save any changed FOV separately.
If there is no camera, add one first. With multiple cameras, also specify the main camera to use for the current interval.
4. Check the movement
 — Play between the two keys in the timeline camera preview. Confirm that the camera keys appear at different frames and that the composition changes as intended.
Check movement between two camera keys
Refine camera movement
Stop playback and go to the frame you want to edit. Adjust its values, save the key again, and play the surrounding interval to check the movement.
